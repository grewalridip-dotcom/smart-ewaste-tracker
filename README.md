# Smart E-Waste Exchange — Item & Status Tracker

A lightweight web application built to streamline electronic waste submission, automated routing, and lifecycle tracking.

## Features
- **Automated Routing Logic:** Classifies submitted devices into **Reuse / Exchange**, **Refurbish**, or **Safe Recycle** based on device condition and age.
- **Lifecycle Status Tracking:** Allows updating each item's processing stage (`Submitted` → `Inspected` → `Processed`).
- **Search & Multi-Filter:** Filter logged items by keyword, pickup location, recommended pathway, or status.
- **Persistent Storage:** Saves all entries locally using Browser `localStorage` with instant summary metrics.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript (ES6+), Browser LocalStorage
